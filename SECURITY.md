# Security policy

JellyPIN is experimental parental-control software and has not received an independent security audit.

Please do not publish authentication bypasses, exposed PIN material, Jellyfin access tokens, or other sensitive evidence in a public issue. Contact the maintainer privately through the contact method listed on the maintainer's GitHub profile until a dedicated security address is published.

Include the JellyPIN version, Jellyfin Server version, affected client, reproduction steps, and whether the issue exposes metadata or permits media playback.
